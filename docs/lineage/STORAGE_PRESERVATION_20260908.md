# 아티팩트 보존과 저장공간 정리

중요 아티팩트는 삭제하지 않고, 원래 경로에서 계속 읽을 수 있게 보존했다. 아래는 이번 추가 작업으로 확인한 **실제 디스크 할당량 감소**이며, 기존 압축 효과나 다른 작업에서 생긴 여유 공간은 포함하지 않는다.

| 완료한 묶음 | 파일 수 | 새로 확보한 공간 |
|---|---:|---:|
| 종료된 런타임의 중복 틱 캐시 무손실 압축 | 8 | 19.38MiB |
| 종료된 밀도 학습 실험의 기록 보존 압축 | 12 | 206.22MiB |
| 종료된 자식 포지션 실험의 자산 곡선 보존 압축 | 8 | 382.42MiB |
| 합계 | 28 | **608.02MiB** |

마지막 8개는 논리적 내용 410,645,728바이트를 그대로 유지하면서 할당량이 410,660,864바이트에서 9,662,464바이트로 줄었다. 압축 명령은 각 파일에 한 번씩 실행했고 모두 정상 종료했다. 각 명령의 원본 출력 바이트, 종료 코드, 작업 전후 해시·경로·할당량을 파일별로 즉시 저장했다.

추가로 조사한 20개 중 12개는 이미 LZX 압축 상태여서 다시 압축하지 않았다. 일반 파일 속성이 `Archive`여도 실제 압축이 적용돼 있을 수 있어 Windows의 실제 압축 정보를 확인했다. 20개 전부 원래 내용·길이·경로가 유지됐고, 18개 완료 매니페스트와 4개 종료 기록도 보존됐다.

소스, ONNX 모델, 학습·거래 상태, 중요한 실험 결과와 유일한 필수 시세 원본은 보존 대상으로 유지한다. Live-Dev와 Lab에는 작업하지 않았다. 마지막 압축 중 여유 공간 최저치는 38,316,511,232바이트로 30GiB 기준을 지켰다. 최종 확인 시 여유 공간은 약 35.9GiB였다.

재생성 가능한 중복 캐시 800개, 논리 용량 약 10.03GB의 삭제 계획은 보존돼 있다. 실제 삭제는 **0개**다. 자동 승인 검토가 전체 명령과 축소한 세 파일 명령을 실행 전에 거부했고, 반환 사유는 `blocked by policy`였으며 더 구체적인 설명은 없었다. 다른 경로로 삭제를 우회하지 않았다.

전체 근거는 [최종 보존 기록](../../lineage/STORAGE_CLOSED_V7_ARCHIVE_LZX_20260908_ROOT_RETENTION_V1.json), [8개 압축 결과](../../lineage/STORAGE_CLOSED_V7_ARCHIVE_LZX_20260908_V1_RESULT.json), [삭제 차단 기록](../../lineage/STORAGE_REBUILDABLE_DUPLICATE_TKC_DELETE_20260908_STATUS_V1.json)에 있다. 임시 실행 코드도 최종 보존 기록에 원본 바이트로 담았다.
