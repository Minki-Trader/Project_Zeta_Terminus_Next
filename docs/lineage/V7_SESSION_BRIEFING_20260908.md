# V7 개발 세션 브리핑 — 2026-09-07~08

현재 진행하던 Family23의 구현·실제 Tester 비교·증거 보존을 완료하고, 사용자 요청에 따라 개발을 일시 정지했다. 이번 세션에서 23개 실험 묶음을 검토했고, 이 중 9개는 실제 MT5 실행까지 진행했다. ONNX와 온라인 학습은 구현·작동 확인을 마쳤지만, 전체 조건을 통과한 V7 개선판과 실제 복리 확대는 확보하지 못했다. 이전 실험의 실패 판정은 유지한다.

## 무엇을 개발했나

V7를 기준으로 ONNX 모델의 예측을 실제 MT5 EA에 연결하고, 거래 결과가 확정된 뒤 다음 판단을 보정하는 온라인 학습을 구현했다. 위험 배분, 진입 선별, 손절·청산, 수익 중 재투입, 추가 주문 등 여러 방법을 평가했다. 외부 발표·뉴스·경제 지표 자료를 모델 입력으로 쓰지 않았다. V7의 EA/MQH와 자체 거래 기록, MT5의 기존 시세만 사용했다.

마지막 Family23은 기존 V7의 여섯 신호와 기존 청산 규칙을 유지한다. 고정 ONNX 모델이 거래별 위험 예산을 조절하고, 보수적으로 계산한 자기 자본에 비례해 시장가 주문 수량을 정한다. 온라인 버전은 자신이 실제로 종료한 거래의 손익을 그 거래의 최초 위험으로 나누어 학습한다. 같은 초에 결정하는 거래끼리는 같은 학습 상태를 사용하며, 이후 초의 결정부터 확정된 결과를 반영한다. 지정가 Passive 전략의 주문 수량은 기존 0.01 lot를 유지한다.

쉽게 말하면 V7가 매수·매도할 기회를 찾고, 추가한 모델이 그 거래에 배정할 위험을 조절한다. 온라인 학습은 끝난 거래를 보고 다음 판단을 조금씩 수정한다. 예를 들어 보수적 자기 자본이 $100에서 $200 이상으로 올라가면, 거래소가 허용하는 단위와 기존 위험·증거금 검사를 통과한 시장가 주문은 0.01에서 0.02 lot로 커질 수 있다. 수량이 커지도록 코드를 작성한 것과 실제 복리 성과가 확인된 것은 구분한다.

ONNX·온라인 학습 버전은 기존 Live-Dev와 별도의 개발용 소스, 실행 파일, 설정, 상태, 주문 식별번호, Portable, 증거를 사용한다. Live-Dev에 배포하거나 운영 설정을 바꾸지 않았다.

## 보존·제한·정지 범위

학습이 실제로 실행된 것, 수량이 실제로 커진 것, 투자 성과가 개선된 것은 서로 다른 증거다. 하키스틱 성장은 보장하지 않았으며, 전체 조건을 통과하지 않은 후보를 Live-Dev 개선판으로 승격하지 않았다. 상태를 파일에 저장하고 다시 읽는 것은 확인했지만, 프로세스 재시작 후 학습을 이어가는 동작을 실제로 입증했다고 주장하지 않는다.

압축 작업별 실제 할당량 감소를 합산하면 **7.24 GiB**다. 이는 이전 WOF 압축 기록이나 디스크 전체 여유 변화와 중복 합산하지 않은 이번 NTFS 작업 시점의 수치다. 요약 작성 시 C: 여유는 **34.15 GiB**, 최소 유지선은 30 GiB다. 모델·소스·학습 상태·최종 결과·중단 이력을 보존했다. Family23 원본 입력·출력과 소스 518개, 823,942,615바이트의 보존을 확인했다. 이후 추가된 최종 문서·종료 기록은 별도로 연결한다.

삭제는 사용자가 명시적으로 승인했으나, 실행 도구가 명령 시작 전에 `exec_command failed: CreateProcess Rejected: blocked by policy`를 반환했다. 그 외의 차단 원인은 제공되지 않았다. 정리 명령으로 실제 삭제한 파일은 0개다. 다른 삭제 경로로 우회하지 않았다. 일반 NTFS 압축은 파일을 그대로 유지하며 수행했다. 네이티브 Tester가 다음 실행 준비 중 이전 작업용 사본을 교체하는 경우에도 정식 원본 증거 아카이브를 먼저 보존했다.
