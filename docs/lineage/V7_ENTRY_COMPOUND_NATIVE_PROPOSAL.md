# 최초 V7 복리 모델의 실제 Tester 평가 제안

현재 상태는 **제안만 작성, 모델 복사·새 EA·실행 없음**이다. 일반 V7 개발과 Tester 실행은 이미 허용되어 있다. 이번에 필요한 결정은 종료된 최초 모델을 아래의 고정 범위에서 한 번 다시 사용하는 예외다.

최초 실험은 원본 V7 거래 기록에 모델 점수를 적용하는 선별에서 탈락했다. 정적·온라인 방식의 위험조정 수익 보존율은 각각 약 74.33%, 73.09%로 당시 90% 기준에 못 미쳤다. 이 실패는 그대로 보존한다. 실제 EA에서 바뀐 수량, 손절거리, 공유 계좌 위험과 자체 거래 결과에 따른 온라인 갱신은 아직 실행하지 않았다.

## 실행 범위

| 항목 | 고정 내용 |
|---|---|
| 기반 | 현재 동결된 원본 V7의 Optimization 복사본 |
| 모델 | 최초의 561바이트 ONNX와 1,822바이트 2024 초기 모델 정보만 사용 |
| 비교 | 원본 → 정적 방식 → 원본 → 온라인 방식, 총 4회 |
| 기간 | 2025년 전체, 시작 자본 $100, 레버리지 1:100 |
| 입력 | US30·US100·US500 모두 100% 실제 틱, 동일한 입력·계약·실행기 버전 |
| 바뀌는 동작 | 최초 선언 그대로 자본에 비례한 시장 주문 수량과 모델 점수에 따른 개별 위험 예산 |
| 유지 | 원본 신호·방향·거래 시각·청산·Passive 0.01, 전체 위험 한도 12% |
| 온라인 | 자체 거래가 완전히 끝나고 다음 결정 시각보다 앞선 결과만 사용; 갱신율 0.03, 보정값 한계 ±0.5 유지 |

재학습, 임계값 조정, 수량 공식 변경, 다른 종료 모델의 결합은 포함하지 않는다. 새 소스와 별도 Tester 런타임을 사용하며 Live-Dev와 Lab은 그대로 보존한다.

## 통과 기준

- 원본보다 최종 자산과 로그 성장이 높고, 비용을 두 배로 반영한 보수적 순이익이 최소 5% 높아야 한다.
- 회복력이 개선되어야 하며, DD는 원본 이하를 기본으로 한다. 소폭 악화 허용 범위는 원본 +1.5%p와 원본 ×1.10 중 작은 값이며, 다른 성장·회복·기간 조건을 모두 만족해야 한다.
- 상·하반기 실제·보수적 손익이 모두 양수여야 한다. 모든 거래·거절·손실과 완전한 자산 경로를 보존한다.
- 자기 수익으로 실제 주문 수량이 증가한 기록이 있어야 복리 재투자를 관찰했다고 말할 수 있다. 하키스틱 성장을 보장하지 않는다.

모든 기준을 만족하는 한 방식만 동일한 상태로 2025년부터 2026년 8월까지 연속 확인에 진입할 수 있다. 확인 단계의 저장공간은 별도로 확보한다. 둘 다 탈락하면 함께 종료한다.

## 저장공간과 근거

새 런타임 4GiB, 원시 기록 1GiB, 소스 32MiB를 상한으로 잡았다. 30GiB를 남기려면 시작 전에 총 37,614,518,272바이트가 필요하다. 제안 직전 여유 공간은 40,440,127,488바이트였다. 실제 시작 직전과 실행 중에도 전체 남은 성장분을 다시 확인하며, 아직 하지 않은 압축의 예상 절감량은 예산에 넣지 않는다.

정확한 해시·수식·조건은 [고정 제안](../../optimization/evidence/V7_ENTRY_COMPOUND_NATIVE_COMPLETION_PROPOSAL_V1.json)에 있다. [전체 개선 방향 비교](../../optimization/evidence/V7_ML_POST_DENSITY_WHOLE_MAP_COMPARE_V1.json)는 인접한 기존 실험을 새 접근으로 이름만 바꿔 여는 대신 이 미실행 항목을 제안한 이유를 기록한다.

확인이 필요한 근거는 [운영 방향](../OPERATING_DIRECTION.md)의 종료 실험 보존·인접 후속 제한과 [최초 실험 종료 기록](../../optimization/campaigns/v7-onnx-online-compounding-v1/evidence/CLOSURE_V1.json)이다. 예외가 승인되기 전에는 이 모델을 복사하거나 새 후보를 실행하지 않는다.
