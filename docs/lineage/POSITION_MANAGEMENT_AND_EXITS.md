# 포지션 관리·청산·보호

- 고정 SL/TP, BE, trailing, partial, 조기청산, 수익잠금, 상태·경로·위험 기반 관리가 각 전략별로 검토됐다.
- RC16, Cross, Pressure, Return은 현재 accepted-V5 HOLD를 유지하고 Passive는 기존 상태반응형 HOLD를 유지한다.
- B48의 RC4 adverse-risk compression만 반복 가능한 경제 개선을 통과했고, B49/B52/B66/B67/B70은 그 조치의 인과·복구·영속성만 경화했다.
- All-Six HOLD/CLOSE 연구는 완전정보 상한은 확인했지만 근처 상태의 효과 구조가 없고 무조건 CLOSE가 손실이어서 실행 정책을 만들지 않았다.
