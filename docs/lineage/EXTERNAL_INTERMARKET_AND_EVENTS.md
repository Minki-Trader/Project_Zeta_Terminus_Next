# 외부시장·교차자산·경제 이벤트

- FX, 금속, 원유, ETF, 암호자산, Cboe 변동성, CFTC 포지셔닝, 재무부·DOL·EIA 발표, SEC/FINRA 등 다양한 외부 정보가 독립적으로 검토됐다.
- 데이터의 무료성, 공개시각, 수정·지연, 최신구간 격리와 브로커 시계의 인과성이 항상 경제 결과보다 먼저 검증됐다.
- B61~B65 및 B72~B74 계열의 외부 이벤트 기반 조기청산은 반복 가능한 비용·위험 개선을 만들지 못해 각 전략의 HOLD를 유지했다.
- 외부 데이터는 현재 V7의 입력이 아니며, 과거 설명 결과가 자동 실행권으로 승계되지 않는다.
