# 포트폴리오·자본·위험

- 초기 개별 전략은 공유 `$100` 잔고·equity·margin·비용 스트레스 포트폴리오로 통합됐다.
- 현재 기준은 참조자본 `$100`, FPMarkets `1:100`, 기본 `0.01` lot, 포지션당 4%, 합산 12%, margin 45%, 추가위험 reserve/headroom을 포함하는 유한위험 계약이다.
- stage balance는 `$100 + 프로젝트 귀속 실현손익`이며 입출금·credit·balance adjustment를 제외한다.
- V7은 V6R6 포지션이나 상태를 채택하지 않고, 최종 flat 인계 때 확정된 프로젝트 귀속 실현손익만 prior-realized 입력으로 이어받는다.
