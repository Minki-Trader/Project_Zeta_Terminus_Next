# Turnover Value Frontier V1

This active source-free Lab family owns Program 5 / macro Unit 074. It asks whether higher component frequency is stably associated with lower stressed value per fill across both the fixed-0.01 CP2 book and the independent compounding binding book, with four-period breadth.

The finite bundle uses exact six-component counts and 2x stressed net only. It reports count/value Spearman, three-low-frequency versus three-high-frequency mean per-fill value, and low-frequency net-share minus fill-share. Component identity, mechanism and clock remain confounded, so even a pass is a future expansion constraint rather than a causal claim or authority to remove components.
