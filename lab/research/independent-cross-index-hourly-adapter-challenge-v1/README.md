# Independent Cross-Index Hourly Adapter Challenge V1

This is the first serial family in the user-authorized independent V8 Challenge program. It is a Program 1 (`entry_signal_market_structure`) Lab research family, not an exact-V8 Optimization campaign and not a Live change.

## Economic question

Can a first-principles, causally refitted three-index hourly forecasting adapter create a standalone US100/US30/US500 portfolio that beats the exact V8 challenge benchmark without borrowing V8 signals, opportunity timestamps, component rules or economic labels?

## Required architecture

- Python owns feature construction, monthly causal model fitting, score calibration and decision-tape production.
- A separate EA owns market validation, risk sizing, order submission, protective stop ownership, fixed-horizon close, persistence and bounded evidence.
- No single-EA economic candidate is permitted. A proxy survivor is only an adapter selection result until its separately identified EA compiles and completes the frozen native path.
- Neither component may include, link, execute or write `live-dev/`, `optimization/`, `lab/mt5/` or another family root. Live V8 remains untouched.
