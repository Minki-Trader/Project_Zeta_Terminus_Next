# Gain-overlay base-quantum reservation V1

This source-free Lab family owns Frontier Unit 097 under Program 5 `portfolio_capital_risk` at macro height. It converts one new optimization-path attribution into a single bounded candidate contract; it does not claim a Lab economic success and does not run MQL, MetaEditor or MT5.

The current qualified optimization anchor used a component-local gain overlay. Forty-two selected entries received larger executable volume, but one enlarged 15:00 position changed the later admission path from a 16:00 Return lifecycle to a 17:00 Cross lifecycle. The exact native-to-native attribution left only `+$1.92 / +$0.417` total improvement after that substitution and later stop-geometry propagation.

Unit 097 freezes one prospective mechanism: a gain overlay may consume aggregate headroom only after one unchanged base position-risk quantum, `4%` of current risk capital, remains available. The reserve applies only to incremental gain-overlay volume. Neutral volume, the original first-come order, the `18%` aggregate cap and every signal, stop and exit remain unchanged.

The paired native paths are already-consumed fit information. They support one optimization seed but cannot establish native drawdown or economic success for the hybrid path. Any evaluation therefore belongs to a new isolated optimization campaign and must pass the full native selection and conditional forward gates without retuning.

The family is closed. It added no source, settings, runtime, broker query, test, validator or Live authority.
