# Family 014 종료 결과

사전 동결한 독립 기준가격 이탈의 즉시 진입·지정가·인과적 취소 세 정책을 모두 종료했다. 전체 원본 틱 경로에서 완결한 이 묶음에는 통과 후보가 없다.

| 정책 | 순손익 | 방향별 두 배 비용 | 양쪽 절반 두 배 비용 | 양의 금융수익 제거 | 평가 낙폭 | 최초 체결/일 |
|---|---:|---:|---:|---:|---:|---:|
| 즉시 진입 | -$99.8526 | -$167.7975 | -$167.54925 | -$168.3489 | 99.8526% | 2.2553 |
| 지정가 | -$99.8703 | -$162.1063 | -$162.29055 | -$162.3477 | 99.8703% | 1.8743 |
| 지정가 + 취소 | -$99.8587 | -$160.5425 | -$160.9363 | -$160.8519 | 99.8587% | 1.9942 |

초기 자금은 정책마다 $100이다. 모든 517개 개발 날짜를 포함했다. 충분한 신호가 있어도 2024년에 자금 대부분을 잃으면서 실제 거래는 1,166/969/1,031회에 그쳤다. 2025년 최초 체결은 0/1/1회이고 평가 손익은 0 또는 음수다. 최소 수량의 3% 위험 상한 때문에 이후 신호 대부분이 거절된다. 자금·위험을 늘려 구제하지 않는다. 수익, 세 비용 평가, 양의 연도, 낙폭, 일당·연간 거래 관문을 모두 실패했고 세 종목·양방향 폭만 통과했다.

지정가 1,548건은 체결 969건과 만료 579건으로 완결된다. 취소 정책의 3,135건은 체결 1,031건·취소 1,310건·만료 794건으로 완결된다. 모든 3,166개 최초 체결 ID와 완전 청산 ID가 일대일로 맞고 마지막 대기 주문·포지션은 0이다. 현금·스프레드·금융비용·양의 금융수익 제거·기간 귀속은 1e-7 이내로 대조된다.

정상 개발 경로는 265,669,627개 호가를 한 번 순회했고 422,449개 주문/상태 기록, 3,166개 완전 거래, 2,121,102개 분 단위 평가 기록을 남겼다. 원래 96개 주 결과·체크포인트는 265,521,401 bytes이며 저장 오류 영수증까지 97개/265,522,305 bytes를 보존한다. 최초 계산은 모든 달과 대조를 마친 뒤 NumPy 참·거짓 값의 JSON 변환에서만 실패했다. 기존 결과를 해시로 고정하고 정상 보고서 마감 단계만 복구했으며 호가 시뮬레이션을 재실행하거나 수치·관문을 바꾸지 않았다.

호가만으로 실제 수량·지연·마진·과거 비용을 증명하지 않는다. 현재 swap 스냅샷, 원본 날짜 자정 금융비용, 수수료 0, 동일 밀리초 종목 순서와 보수적 지정가/목표 체결은 공개한 proxy 한계다. 이 결과는 native MT5 성과나 일반적인 지정가 전략의 불가능성을 뜻하지 않는다. 같은 신호의 인접 수치·기간·종목·방향·청산·위험을 다시 탐색하거나 seed를 남기지 않는다. 2026 후보 자료, EA와 native 후보는 열지 않았고 두 자료 reader는 정상 종료 상태다.

선언·원본·특징·경제 경로·저장 교정·최종 결과의 지문은 `evidence/CLOSURE_V1.json`이 연결한다. 모든 연구 프로그램을 다시 비교한 뒤 다음 단위 하나를 선언한다. Live V7R은 별도 검증본의 entries-disabled 상태를 유지하며 실제 매매 활성화는 사용자가 직접 수행해야 한다.
