# Family 014 — 독립 기준가격 이탈의 진입 시점 비교

Program 3 단일 연구 묶음이다. 직전 60개 완료 M1 중간가격의 평균·모표준편차에서 새로 이탈한 사건을 Python이 만들고, 즉시 진입·추가 가격 양보를 기다리는 지정가·추가 악화 시 인과적 취소를 함께 비교한다. 기존 전략이나 닫힌 family의 신호를 사용하지 않는다. 완전한 숫자·기간·비용·위험·종료 계약은 `config/contract.json`, 선행 선택과 입력 지문은 `evidence/DECLARATION_V1.json`이 소유한다.

현재 자체 입력 확보를 마쳤고 특징 구현도 첫 실행 전에 동결했다. 25개월×3종목 269,321,351개 틱, 16,159,300,260 bytes와 517개 개발 날짜를 확보했다. 자체 no-EA reader PID 25492는 정상 종료했으며 후보 특징·체결·손익은 아직 계산하지 않았다. EA·Include·전략·차트 프로필을 복사하지 않았고 실제 주문이나 계좌·포지션·주문/체결 이력을 조회하지 않았다. `adapter/acquire_inputs.py`와 `adapter/derive_features.py`는 정상 자료·특징 생산 도구이며 별도 시험·검증 CLI가 아니다.

2023년 12월은 준비, 2024–2025년은 개발 기간이다. 월별 원래 Bid/Ask와 밀리초·동일시각 원본 순서를 보존한다. M1 신호는 바로 그 틱에서 만들고 API M1은 날짜 분모에만 쓴다. API 경계 밖 가격은 접근하지 않는다. 틱과 M1의 모든 원본 날짜 합집합에 무신호·지연·진입중단 날짜도 남긴다. 자료 확보가 끝나면 reader를 정상 종료하고 입력 및 새 특징 구현을 동결한 다음 공급 관문을 평가한다.

지정가 생성 호가에서 체결을 인정하지 않는다. 나중 호가의 실제 반대편 가격이 지정가에 도달해야 하며, 이미 발생한 체결·보호 청산보다 취소를 앞세우지 않는다. 목표·손절·수량·대기 중 위험 예약은 계약대로 고정한다. 거래량·마진·과거 금융비용·지연·체결 수량에는 native 확인이 필요하다. 현재 계약의 지정가 허용은 수익성이나 거래소 대기열 우선권의 증명이 아니다.

세 정책은 한 번 선언한 묶음으로 함께 종료한다. 공급·전체 개발·고정 2026 확인을 순차 통과한 단 하나의 정책만 독립 EA와 native 실틱 경제 경로를 받을 수 있다. Python 결과는 V8 승리를 선언하지 못한다. 어떤 단계도 Live 권한을 주지 않는다. 저장 증가 한도 36 GiB와 C: 여유 최소 30 GiB를 유지하며, 자료 수집은 완료된 종목/월 경계에서 정상 중단할 수 있다.

첫 정상 특징 실행은 517개 날짜에 137,096개 낙관적 사건, 134,029개 신선한 사건으로 필요한 공급 관문을 통과했다. 2024/2025 사건은 68,856/68,240이며 네 무신호 날짜와 3,067개 지연 사건을 그대로 남겼다. 이 숫자는 수익이나 체결이 아니다. 변경 없는 세 역할의 `adapter/simulate_development.py`를 첫 경제 실행 전에 동결했다. 정해진 전체 기간과 비용을 계산하고 주문·청산·현금·기간 대조를 모두 마쳐야 판정한다.
