# Mark Extrema Clock Anchor V1

This frozen source-free Frontier family tests whether lifecycle peak and trough
marks align more strongly in server wall-clock coordinates than in elapsed-time
coordinates from entry.

It uses every complete current-spec P4 lifecycle and the logger's preserved
`peak_time_server` and `trough_time_server` fields. Identical 30-minute supports,
pooled concentration, and cross-component histogram alignment distinguish a
shared session clock from a shared duration response without selecting favorable
components, exits, directions, or time windows.

The unit is diagnostic only. It does not change entry clocks or hold schedules,
reopen Unit 060, modify MQL, run Tester, or touch broker, account, runtime, or
Live surfaces. It closes after one bounded aggregation and opens no automatic
clock, hold, window, component, or subgroup successor.
