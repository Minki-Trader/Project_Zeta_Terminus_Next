# SLOOS C&I Credit-Supply Impulse Book State v1

Status: declared, official-source acquisition and portfolio outcomes unopened.

This directory owns the single Program 2 / Unit 095 experiment asking whether a causally available quarterly tightening impulse in domestic-bank C&I lending standards is materially adverse to the existing US30 book relative to the existing US100 book.

The complete declaration-to-verdict path is one research experiment. Source acquisition, parsing, serialization and implementation corrections are internal audit events and have no arbitrary numeric cap while the frozen economic contract remains unchanged. A valid source freeze may feed one successful fixed economic aggregation; economic metric reruns or post-result gate changes are forbidden.

The bundle is intentionally narrow: Federal Reserve SLOOS Table 1, Question 1A, domestic All Respondents, large and middle-market C&I credit standards, January 2022 through July 2026. Levels, small-firm standards, demand, terms, CRE, consumer, foreign-bank, threshold, quantile, lag, window, symbol, component and risk variants are not successors.

No MQL source, runtime, compile, Tester, broker/account query, Live research ledger read, or Live change belongs to this family.
