# V7의 다음 native 검증 제안

이 문서는 제안입니다. 다음 모델의 복사·EA 구현·Tester 실행은 아직 시작하지 않았습니다.

기존 V7의 수익 중인 시장가 포지션에 최대 한 번만 같은 수량을 추가하는 기존 ONNX 모델을, 실제 틱으로 끝까지 확인하는 한정 예외를 제안합니다. 여섯 원래 전략과 부모 주문의 규칙은 유지하고, 추가 포지션의 위험도 원래 공통 한도 안에서 계산합니다.

과거 단순 합산 검토에서 온라인 모델의 추가 스트레스 수익은 +$25.42였지만, 추가 거래16회로 사전 최소20회에 못 미쳐 닫혔습니다. 실제 계좌 결과가 아니므로 개선으로 인정하지 않습니다. 그 실패와20회 기준을 그대로 남기고 실제 native 결과를 새로 확인하는 제안입니다.

- 2025년 전체를 **대조군→무조건 추가 기준→대조군→고정 ONNX→대조군→온라인 ONNX** 순서로 실행합니다.
- 그대로인 ONNX1151바이트와2024초기 학습 상태13626바이트만 복사합니다. 옛 EA·Python·2025학습 상태는 사용하지 않습니다.
- 최종 순자산·비용 반영 수익·회복력이 좋아져야 하고, 비용 반영 이익은 대조군보다5% 이상 높아야 합니다. DD 기준과 거래 수 기준은 낮추지 않습니다.
- 통과한 모델 하나만 별도 예산을 확보한 뒤2025년부터2026년8월까지 연속 확인합니다. 추가 주문과 실제 재투자를 구분해 복리 효과를 판단합니다.
- Live-Dev는 전부 유지합니다. 외부 경제 자료는 사용하지 않습니다.

전체2025선별 예산은 runtime3GiB+원본 결과1GiB+소스32MiB이며,30GiB 여유 공간을 별도로 남깁니다. 방금 종료한 연구의258개 파일을 바이트 손실 없이 압축한 실측 여유 공간으로 현재 전체 예산이 확보됐습니다. 실행 직전과 각 경로 사이에 남은 전체 예산을 다시 확인합니다. 이후 연속 확인은 별도의 저장공간 예산 조건입니다.

현재 프로젝트 정책의 닫힌 가족 재개 금지와 이번에 완료한 로그 배분 모델만의 예외 때문에, 이 별도 모델 재사용에는 명시적인 한정 예외가 필요합니다. 일반 Tester 실행은 이미 허용되어 정상 완료했습니다.

정확한 파일 해시, 고정 규칙, 전체 비교·확인 기준은 [상세 제안](evidence/V7_WINNER_CHILD_NATIVE_COMPLETION_PROPOSAL_V1.json)에 기록했습니다.
