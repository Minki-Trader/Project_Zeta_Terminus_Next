## Outcome-free threshold construction

Development signal-passed rows from 2024-2025 define one normalized strength distribution per component. Quantile zero means the exact native gate. Positive quantiles use the deterministic nearest-rank feature value and keep values equal to the threshold. Threshold construction reads no lifecycle outcome.

The complete Stage-A map uses quantile coordinates `0 / 0.25 / 0.50` across all five components: `3^5 = 243` raw roles including the exact-V8 neutral. This prevents selecting only RC61 or Cross from descriptive hindsight. All roles and thresholds are frozen as one bundle before economic evaluation.
