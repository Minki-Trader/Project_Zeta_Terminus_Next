# 상태 기반 보유 방향 학습: 선별 종료

고정·온라인 모델 모두 원본 V7을 대체할 선별 기준에 미달했다. 20회 학습 중 유리했던 회차를 다시 고르지 않았고, 처음 정한 마지막 가중치로 전체 2025년을 평가했다.

원본 V7의 실제 +$127.89 및 스트레스 +$118.609를 넘는 기여, 양쪽 반기 양수, 최소 활동과 20% 이내의 M1 DD 상한이 필요했다. 고정 모델의 수익 대부분은 추가 거래비용을 반영하면 남지 않았고 하반기는 음수였다. 온라인 모델은 손실 이후 주로 관망했다. 이는 원본 개선이나 복리 성장 통과가 아니다.

2024년 20회 전체 학습은 124,260회 추론과 123,600회 갱신으로 정상 완료됐다. 2025년에는 각 8,760개 잠재 시각 중 6,166개 유효 추론, 2,590개 접두 데이터 결측, 4개 현재 가격 부재를 모두 남겼다. 각 모델의 6,166개 상태 전이 중 6,164개가 엄격히 이후 시각에 성숙했고 마지막 2개는 pending으로 보존했다. 입력·선언·소스 바이트는 그대로다.

20시 이후 첫 관측 가격이 다음 날짜에 있던 날은 6일이다. 실제 보유 포지션이 날짜를 넘긴 완결 거래는 고정 1개, 온라인 0개로 별도 집계했다. 단순 지연 날짜 수를 실제 보유 수로 해석하지 않는다.

시뮬레이터는 고정 0.01 수량과 대표 스프레드, 보수적인 분봉 고가·저가 순서를 사용한다. 실제 틱 순서·증거금·금융비용·수수료·일별 native lot·복리·equity DD를 입증하지 않는다. 2026년 후보 데이터와 새 EA·Portable은 열지 않았다. 전체 세 역할을 종료하고 인접 보상·모델·학습·시각·위험 설정이나 seed로 이어가지 않는다. Live는 변경하지 않았다.
