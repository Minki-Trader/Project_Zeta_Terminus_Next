# V7 learned Passive execution

The sole active campaign studies the original Passive limit-price mechanism. It preserves original signals, direction, pending lifetime, fixed0.01volume, portfolio sizing/risk, protection and exits. An ONNX quote-excursion quantile selects the distance of an already valid Passive limit order; an online variant calibrates that quantile using only matured fixed-window price labels.

`evidence/DECLARATION_V1.json` owns the prospective contract. All candidate source, model, input and output stay under this family or its dedicated Optimization runtime/raw root. The exact frozen V7R baseline remains the control parent. Closed models and family sources are not imported. No Live change, external economic dataset or test-only infrastructure is authorized.
