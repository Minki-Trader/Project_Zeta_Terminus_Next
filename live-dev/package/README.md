# Frozen release packages

`active/`는 현재 선택된 정확한 배포 스냅숏이다. `NEXT-E01-V7-CXR1-c0ad2f30d293`의 EA 하나, 필요한 Include tree, EX5, base SET, `SOURCE_MANIFEST.json`과 `RELEASE_MANIFEST.json`만 들어 있다. Lab 변경은 이 디렉터리에 자동 반영되지 않는다.

이 패키지의 존재나 실틱 동등성 통과는 Live 권한을 뜻하지 않는다. 계좌·선행 실현손익을 바인딩한 0/0·1/1 SET과 terminal INI는 Git 밖의 Live Portable에만 생성된다.
